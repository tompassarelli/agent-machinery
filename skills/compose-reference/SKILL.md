# Compose reference

## Contract worksheet

Record a stable kebab-case ID; responsibility and deliverable; task grade;
domain requirements and supplied context; worker or orchestrator topology;
semantic tier and reasoning; posture; canonical capabilities; decisions the
run may make; escalation conditions; observable done criteria; and a compact
report shape.

Every side effect must fit the declared capabilities. A nearest template may
seed values but contributes no authority. Validate the result against
`agent-machinery:contracts/routing-request.schema.json`.
