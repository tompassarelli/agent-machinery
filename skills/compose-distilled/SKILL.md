# Compose a bespoke composition

Read `agent-machinery:doctrine.md`, `agent-machinery:docs/routing.md`, and
`agent-machinery:staffing/catalog.json`. Use unchanged, override only grade,
domains, tier, reasoning, or posture, or compose bespoke for any other mismatch.
Choose axes independently; declare capability, authority, escalation, done, and
report boundaries. Metadata grants no access. Emit the exact eight-field
request with `node scripts/compose-routing.mjs`; keep execution facts outside.

For detail, run `agents path compose-reference` and read its `SKILL.md` fully.
