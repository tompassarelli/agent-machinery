# Staffing reference

## Contract comparison

Compare a candidate template across responsibility, deliverable, topology,
capabilities, decision authority, escalation conditions, done criteria, and
report shape. A mismatch in any of those fields requires a bespoke composition.

## Consumer handoff

Record the chosen function or role, task grade, domain requirements, topology,
semantic tier, deliberation, posture, and composition. Include canonical
capabilities and the context satisfying domain requirements. Generated agent
templates are neutral behavior contracts; provider/model/account selection and
runtime access mapping belong to the consuming harness.
